분석 방법

결과는 이렇게 계산했어요

  1. 2022~2023년 공식 파일과 2024~2026년 API 자료를 불러옵니다.
  2. 주택유형이 일치하고 보증금·면적이 유효한 거래만 남깁니다.
  3. 각 거래의 보증금을 임대면적으로 나누어 ㎡당 전세가를 구합니다.
  4. 입력 예산을 평균 ㎡당 전세가로 나누어 예상 면적을 계산합니다.

예상 면적은 실거래 평균을 이용한 참고값이며 현재 매물의 가격이나 계약 가능 여부를 보장하지 않습니다. 2026년 자료는 연중 누적 자료입니다. 지도는 현행 법정동 경계를 기준으로 표시합니다.
